# Classical Classifiers and Imbalance Corrections for Multi-Label Indonesian Hate Speech

This repository contains the code, data splits, run logs and out-of-fold predictions for the study *Comparative Study of Classical Classifiers and Imbalance Corrections for Multi-Label Indonesian Hate Speech*. The study uses the 12-label Indonesian Twitter corpus of Ibrohim and Budi (2019).

## Authors

Athallah Azhar Aulia Hadi, Yazid Dahren Fauzan, Rahadian Mirza Effendi, and Muhammad Luthfi Aziz Sunarya, Universitas Padjadjaran.

## Overview

The study compares complement naive Bayes, a linear support vector machine (SVM), XGBoost, and a multilayer perceptron on TF-IDF features, with fine-tuned IndoBERTweet as the transformer reference. Three levels of imbalance correction are compared:

- data level: MLSMOTE and ML-ROS oversampling
- algorithm level: class weighting and imbalance-aware losses (focal and asymmetric loss)
- decision level: per-label threshold tuning

Each classifier is run with binary relevance (BR) and classifier chains (CC). All models use the same 12,773 deduplicated tweets and the same five folds from iterative stratification. Hyperparameters and thresholds are chosen on an inner validation split only, so the outer test folds are never used for any selection. Models are compared with a paired permutation test and the corrected resampled t-test, with Holm correction. A cross-corpus test on IndoToxic2024 checks how the models transfer to newer data.

Main results (mean over five folds):

| Model | Macro F1 |
|---|---|
| Linear SVM, best classical model | 0.684 |
| IndoBERTweet | 0.757 |
| Transformer ensemble (3 IndoBERTweet seeds and IndoBERT) | 0.778 |

Per-label threshold tuning gave the most consistent gains for the classical models. Oversampling never improved on no treatment. Classifier chains reduced label-hierarchy violations of the linear SVM from 25.3% to 2.6% without lowering macro F1. See the paper for the full results and statistical tests.

## Repository structure

```
Indonesian_Multilabel_Hate_Speech_Detection_Structured.ipynb      main notebook used for the paper (English)
Indonesian_Multilabel_Hate_Speech_Detection_Structured_ID.ipynb   the same notebook with Indonesian text
Deteksi_Ujaran_Kebencian_MultiLabel.ipynb                         earlier single-notebook version, kept for reference
runner/controls_mnb_loss.py                                       follow-up controls: multinomial NB and MLP with focal and asymmetric loss
runner/gpu_runner.py, runner/run_pending_thr.py, setup_gpu.bat    optional helpers for running long jobs on a local GPU
data/processed/data_clean.csv                                     cleaned and deduplicated corpus with tweet IDs
results/folds.json                                                fold assignment (do not regenerate)
results/experiments.csv                                           one row per run (configuration x fold) with all metrics
results/experiments_ext.csv                                       follow-up experiments: ML-ROS, character features, transformers, ensembles
results/experiments_controls.csv, results/stats_controls.csv      results of the follow-up controls
results/grid_selection_log.csv                                    inner validation scores and the selected hyperparameters per fold
results/preds/, preds_ext/, preds_controls/                       out-of-fold scores per run (.npz)
results/crosscorpus/                                              transformer scores on IndoToxic2024
figures/                                                          figures generated by the notebook (300 dpi)
requirements.txt                                                  Python dependencies
```

The raw corpus (`data/raw/`) and IndoToxic2024 (`data/external/`) are not stored in the repository. The notebook downloads both when they are missing.

## Reproducing the results

1. Install PyTorch for your hardware (see https://pytorch.org/get-started/locally/), then run `pip install -r requirements.txt`.
2. Open `Indonesian_Multilabel_Hate_Speech_Detection_Structured.ipynb` and run all cells from the top. The run flags (`RUN_GRID`, `RUN_GPU_MODELS`, `RUN_BERT`) are set in the first configuration cell.
3. To rerun the follow-up controls, run `python runner/controls_mnb_loss.py mnb` or `python runner/controls_mnb_loss.py mlp` from the repository root.

Runs already recorded in `results/experiments.csv` are skipped, so a full rerun with the stored results only rebuilds the tables and figures. XGBoost, the MLP and the transformers use CUDA when it is available. Without a GPU, these models are skipped and the stored results are used.

Two sources of nondeterminism were removed. scikit-learn's `TfidfVectorizer(max_features=...)` breaks ties at the vocabulary cutoff in an unstable order, which changed macro F1 by up to 0.014 between machines on this corpus. The notebook breaks these ties alphabetically. The neighbour search in MLSMOTE is also deterministic. After both fixes, results from two machines matched for 136 of 145 CPU runs, and the remaining differences were at most 0.001 macro F1 at the configuration level.
